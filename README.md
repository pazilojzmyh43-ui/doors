# Портал — интернет-магазин дверей

Курсовой сайт на классическом Django (Python, шаблоны, SQLite, CSS). Без React.

Компания: ООО «Портал», Псков. В каталоге три категории по пять дверей: входные, межкомнатные и входные для частных домов.

## Запуск

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py seed
python manage.py runserver
```

Команда `seed` заполняет базу и ещё раз выставляет учебные пароли.

## Роли

| Кто | Логин | Пароль | Что может |
| --- | --- | --- | --- |
| Гость | — | — | Главная, каталог, новости, видео работ, контакты, регистрация |
| Клиент | `client` | `ClientPortal!26` | Корзина, оформление заказа, свои заказы: просмотр, правка, удаление |
| Менеджер | `manager` | `ManagerPortal!26` | Все заказы клиентов и смена статуса |
| Администратор | `admin` | `AdminPortal!26` | Категории, каталог, новости, видео, регистрация менеджера, удаление клиентов и менеджеров |

Гость регистрируется сам и становится клиентом. Менеджера создаёт только администратор.

Главная: название, логотип, аннотация и три последние новости. Фон героя — видео шоурума. Отдельная страница «Наши работы» показывает ролики с прошлых заказов из базы.

При добавлении категории название проверяется без учёта регистра. Повтор «Входные» / «входные» не сохранится.

Стандартная админка Django доступна по адресу `/admin/` под логином `admin`.
